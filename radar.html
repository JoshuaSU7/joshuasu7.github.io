X-Band Phased Array RADAR Antenna Board

Overview

What Is This Project?

A phased array antenna steers a beam electronically, by controlling the relative phase of the signal driving each radiating element, rather than by physically rotating a dish. This project is the antenna half of a small X-band RADAR system: an RF transverter chain (local oscillator, mixer, filtering, and amplification) generates a signal around 10.5 GHz, which is then fed into this phased array board. My focus here is the array itself — element layout, feed network, and phase control — so the system can steer its beam without any moving parts.
